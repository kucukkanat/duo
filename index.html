Colophon

How Duo Lab knows you unfolded

Safari doesn't tell a web page that your iPhone folds. There's no hinge angle and no posture API. What it does report is that the window changed size.

Both screens have almost the same shape. So Duo Lab watches the short side of the window. If it passes 560 px on a touch screen, the book is open. Every experiment listens for that moment and turns it into something new.

Other phones don't fold, so the Unfold button simulates the same change.

Keep the booklet. Tap then Add to Home Screen and it opens full screen, like an app.
